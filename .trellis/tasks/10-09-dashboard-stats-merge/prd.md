# 主页统计精简为合并 KPI

## 问题

主页（`src/pages/Dashboard.tsx`，777 行）目前有两块割裂的统计：

1. **使用统计**（代理请求，数据源 `UsageSummaryCards` / 代理日志库）：请求数、费用、实际 token（新鲜输入/输出）、缓存 token。
2. **会话统计**（本地会话扫描，数据源 `useDashboardStore` → `get_dashboard_stats` / stats cache）：可折叠，内含总 token、会话数、消息数、每日趋势面积图、模型占比环图、模型明细表、24 小时时钟图、项目列表。

两块的口径不同、视觉风格不同、都有 token 指标，用户看不出区别，主页也过长。

## 已确认决策（2026-10-09）

**主页只保留一行精简 KPI**，所有图表与明细移到 `/usage` 页面。

## 需求

1. **主页 KPI 行**（一个卡片，单行，窄屏自动换行），固定近 7 天窗口：
   - 请求数（代理）
   - 费用（代理）
   - Token 总量（代理实际 token；当代理无数据时回退显示本地会话 token，并标注"本地会话"）
   - 提问数（本地 history.jsonl，近 7 天）
   - 会话总数（本地，副文案显示项目数）——项目没有最后活跃时间字段，"活跃项目"改为累计口径
   - 前四项附 7 天迷你 sparkline（代理用 `get_usage_trends` 按天分桶，本地用已有数据，不新增后端接口）
   - 卡片右上角"查看详情 →"跳转 `/usage`。
2. 每个 KPI 用小字标明数据来源（代理 / 本地会话），用 tooltip 解释口径差异。
3. **移除**主页上的：会话统计折叠区、每日趋势图、模型占比环图、模型明细表、时钟图、项目列表。
4. **`/usage` 页承接**：新增"本地会话"分区（tab 或 section），迁入趋势图、模型占比、模型明细、时钟图、项目列表；复用现有组件，从 `Dashboard.tsx` 拆出到 `src/components/usage/session/*`。
5. 主页的模块入口 / 快捷操作等非统计内容保持不变。
6. 加载状态：KPI 使用骨架屏；任一数据源失败只影响对应 KPI（显示 "—"），不影响整行。
7. i18n 中英齐全；删除不再使用的翻译键。

## 验收标准

- [ ] 主页统计区只有一个 KPI 卡片，首屏无需滚动即可看到全部 KPI 与模块入口。
- [ ] 代理无数据时 token KPI 回退到本地会话数据，并显示来源标签。
- [ ] `/usage` 的"本地会话"分区可以看到原主页的全部图表，功能（hover、刷新统计）不丢失。
- [ ] `Dashboard.tsx` 行数显著下降（目标 < 300 行），图表组件独立成文件。
- [ ] 亮/暗主题显示正常；`npm run build` 通过，无未使用的 import。

## 非目标

- 修改后端统计口径或新增后端接口。
- 改动 `/usage` 现有的代理统计部分（筛选、三张明细表）。
